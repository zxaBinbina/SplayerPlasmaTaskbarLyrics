# 第一版实现结构

- `shared/settings.json`：设置 schema 与默认值的唯一来源。Plasma 原生小部件配置窗口编辑配置。
- `plugin/runtime.js`：构建为官方可导入的独立 JS 脚本。
  API 级别 5，声明 network/control/api；接收 trackChange、lyricChange、lineChange、
  playStateChange，并每 300 ms 查询 getNowPlaying/getStatus。
  播放模式使用 setPlayMode；按需检测 API 5 的 getQueue，旧宿主保留其他功能。
- `helper/sptl/`：Python 3.10+ 标准库 HTTP 服务。只绑定 IPv4 loopback，
  统一共享配置、连接状态、主题和本地封面；systemd 用户服务负责重启。
- `plasmoid/contents/ui/`：共用 QML 组件。独立 Plasma 5/6 入口和包元数据，
  最低目标 Plasma 5.27 / Qt 5.15 和 Plasma 6 / Qt 6。

## 协议 v1

1.0 增加 `setVolume`（0–1 的绝对值），原 `volume` 仍表示滚轮的相对增量。
`startLiked` 使用官方 `api.call` 读取网易云登录状态、喜欢曲目 ID 和歌曲详情，
交给 `playTrack`、`addToQueue` 播放；按 500 个 ID 请求详情、按 50 首批量插入，
逆序插入批次以保留歌曲列表顺序，保留已有队列。错误区分未登录、空列表和 API 不可用。
未连接时，辅助程序保留一次 45 秒内有效的启动意图，并唤起 SPlayer；
首个插件会话建立后投递一次命令，启动失败取消意图。意图仅保存在内存，不跨服务重启。
窗口启动和唤起在 HTTP 状态锁外执行，避免阻塞播放快照。

SP 插件 POST `/exchange`：session、locale、track、playback、
lyricRevision、播放模式能力、队列分页和命令错误；歌词变化或连接恢复时附带 lines。
响应包含 needLines 和待执行 commands。
每个命令有 ID，插件执行后回传 ack；HTTP 响应丢失会重复投递相同 ID，
插件在执行前记录 ID，防止重复切歌。命令 3 秒过期，断开或新 session 会清空。
这是有界去重机制；插件崩溃瞬间的命令不作跨进程重放。

小部件每 500 ms GET `/state?revision=N`。响应始终包含播放锚点，
内容版本改变时才发送配置、歌曲及完整歌词，避免每次传输大歌词数组。
播放锚点包含 SP 发出的 timestamp、position、speed、offset；
QML 每 33 ms 按时间戳插值，暂停状态不插值，歌词时间为 position + offset。
歌词点击跳转减去 offset；进度条使用歌曲播放时间。

POST `/command` 的启动／唤起和收藏由辅助程序执行，其他控制投递给 SP 插件。
收藏通过 `tray.py` 读取经过身份核对的 SP StatusNotifierItem 的 DBusMenu，
从中英文字段读取真实收藏状态，每次点击前重新解析菜单 ID，触发 SP 自身的收藏操作；
不写入歌曲数据库，不绕过 SP 的来源分发或登录逻辑。托盘不可用时按钮禁用。
收藏请求包含曲目标识，避免旧界面的点击作用于已经切换的歌曲；D-Bus 操作不持有 HTTP 状态锁。

私人 FM 优先读取宿主的 `fmMode` 标记；当前 API 5 没有该标记时，按网易云当前曲目与普通队列当前项
是否一致推断 FM。该读取在后台运行，不阻塞歌词交换，读取失败或曲目变化时禁用 FM 操作。
`dislike` 命令在辅助服务和插件两边核对曲目标识；插件再次读取最新 FM 状态，使用官方
`api.call("netease", "fm_trash", ...)` 反馈实际播放秒数，再通过 SPlayer 原生下一首推进 FM。
反馈期间曲目已变化时不再切歌。重复命令沿用现有 ID 去重。FM 时隐藏播放模式，两处上一首都替换为不喜欢。
未公开 FM 标记的宿主存在识别限制：FM 曲目恰好等于普通队列当前项时，需要后续曲目变化后才能识别。

唤起主窗口不再依赖当前 SP 中返回成功却不恢复窗口的 MPRIS Raise。
辅助程序核对 SP 托盘身份后调用 StatusNotifierItem.Activate，触发 SP 自己的窗口恢复；
托盘缺失时调用原启动入口，由 SP 的单实例处理器恢复主窗口。

弹窗中的播放列表按 50 首分页读取，首次定位当前曲目所在页，可刷新、翻页和点击播放。
打开列表时每 2 秒刷新当前页，内容未变时保留手动滚动位置；队列缩短时回退到有效页面。
选择歌曲时，辅助程序和插件分别核对索引与歌曲标识，插件读取最新完整 Track 后交给 playTrack，
避免过期队列点击播放另一首歌。列表读取失败不影响歌词轮询，失败命令仍确认并显示错误。
关闭弹窗停止列表刷新；返回歌词恢复跟随。悬停收藏开关独立于弹窗收藏，
三／四个悬停按钮的宽度均计入任务栏尺寸和缩放，保留适合内容模式的宽度稳定规则。
GET `/cover` 提供当前歌曲位于 SP covers 缓存目录内的图片，
以及当前 SP MPRIS 发布的 streaming-cover 临时图片，不接受文件路径参数。
POST `/settings` 接收配置窗口已应用的设置补丁，校验并原子保存后更新内容版本。
它不要求 SP 正在运行；多个小部件通过下一次 `/state` 请求接收相同设置。
请求限制 Host/Origin/Fetch-Site；控制和设置请求要求 JSON、自定义客户端标记与运行时
capability，拒绝普通浏览器跨域调用。当前设计针对同一台机器上的桌面集成，
不把同机进程视为隔离的远程客户端。

## 配置和主题

全部外观与交互配置在 Plasma 小部件的原生配置窗口修改，点击“应用”后保存。
`ConfigGeneral.qml` 根据共享 schema 生成中英文表单，使用 `cfg_settingsRequest`
接入 Plasma 的应用／取消流程。`SettingsSync.qml` 在小部件生命周期内发送补丁，
因此点击“确定”后关闭配置窗口不会取消保存；连接暂时中断时自动重试。
小部件配置中的请求仅作为一次编辑记录，重新加载小部件时不重放旧请求。
辅助程序保存的 `XDG_STATE_HOME/sptl/settings.json` 是全局配置的权威来源。
设置分类通过相同的 Bridge 语言来源显示中文“设置”或英文“Settings”。
跟随 SP 时无法读取主题或桥接中断，设置页显示警告，并回退到 Plasma 配色。
KDE 的预定义许可证不包含 AGPL；构建时从项目 LICENSE 生成 LicenseText.js，
设置窗口生命周期内将该全文提供给原生 About 页的 metaData.licenseText。
该绑定由配置窗口的页面宿主持有，切换离开设置页后仍有效；不修改 KDE 系统文件或 AGPL 标识。
新 SP 插件不注册外观设置或发送设置；旧插件仅在没有已保存配置时迁移一次，
以后不能覆盖 Plasma 中的修改。更新辅助程序即可兼容仍在运行的旧插件。

按用户后续要求，任务栏组件随面板高度自动缩放，字号设置成为组件高 42 像素时的基准值。
通过 `Plasmoid.CanFillArea` 使用完整可用面板高度，避免主题的图标区域边距压缩布局。
封面、间距、文字和播放按钮按当前高度相对 42 像素的比例缩放，封面不再固定封顶 42 像素。
独立测量基准字号的两行文字高度，在面板过矮或基准字号过大时进一步缩小渲染字号，
保持两行完整显示。文字与封面整体垂直居中；按钮在最大宽度不足时缩小到可用空间。
组件的隐式高度始终为 42 像素，最小高度为 16 像素，实际高度由面板分配，
避免内容缩放反过来改变面板高度。多个面板仍共享基准字号，但按各自高度独立适配。

界面动画默认开启，时长取 Kirigami 的 longDuration／shortDuration，跟随 KDE 动画速度；
弹窗歌词与播放列表在固定内容视口内交叉淡入淡出并轻微横向滑动，底部控制区保持位置。
快速切换从当前进度反向过渡，退出页面立即禁用交互；关闭弹窗或关闭动画会立即结束过渡。
共享设置 animationsEnabled 可关闭。歌词切换立即更新文本与逐字时间，随后执行淡入和轻微上移，
连续换行会重新开始当前过渡，不延迟播放状态。Taskbar 的 targetWidth 表示最终宽度，
visualWidth 表示宽度动画进度，layoutWidth 表示对 Plasma 预留的空间。
仅所在面板处于“适合内容”时，展开一次预留目标空间、收缩结束后一次释放空间，
避免面板因每一帧动画都调整窗口尺寸而闪烁。内部内容行使用完整预留空间，
控制区在淡入／淡出期间保留完整按钮宽度并贴住组件边缘，歌词占据剩余空间；
避免外部已展开、内部仍窄导致按钮挤压文字，或长歌词无法使用新增空间。
填满宽度、自定义长度及未提供宽度模式的宿主保留原有逐帧布局宽度动画。
通过当前 Window 的 lengthMode 属性判断并监听模式切换，多个面板独立处理；
切换模式时立即完成正在运行的宽度动画。此判断独立于组件自身的自动／固定宽度设置。
最大宽度降低及离线隐藏立即生效；面板高度变化立即完成尺寸动画，保持内容适配。
控制区的布局宽度和透明度同步变化，退出悬停后立即禁用按钮。
任务栏四个操作按钮禁用浮动文字提示，保留图标、交互反馈和无障碍名称；弹窗内仍显示提示。
每个滚轮事件从当前预计音量加减 5%，立即发送一次绝对 `setVolume` 命令并附带 `osd: true`。
辅助服务优先通过 SPlayer 的 MPRIS `org.mpris.MediaPlayer2.Player.Volume` 属性直接设置音量。
原生操作在播放状态锁之外执行，成功时不进入插件命令队列，并同步当前音量；
MPRIS 不可用或写入失败时将同一目标交给现有插件通道。
已有插件音量命令尚未确认时，新输入暂沿用该通道，确认后恢复优先原生，防止旧命令覆盖新的原生设置。
滚轮使用同一目标百分比立即显示 KDE 原生 OSD、SPlayer 名称和原版图标，在释放状态锁后调用
`org.kde.osdService.mediaPlayerVolumeChanged`。0%／100% 处继续滚动仍显示反馈，
每次仍发送一次设置，不合并或等滚动结束后发送。`/state` 的 `pendingVolume` 包含正在执行的原生目标与待确认的插件目标。
滚轮与弹窗滑块的每次输入带上小部件独立的 `volumeClient` 和递增 `volumeSequence`；倒序到达的旧请求不再设置音量。
原生 OSD 调用串行执行，已经被较新请求替代的旧提示跳过，避免并发桌面调用把显示拉回旧目标。
滚动后 1.5 秒内和仍有待确认音量命令时保持预计值，忽略延迟到达的旧音量；
滚动结束且命令已确认后，实际值不同才调用本地 `volumeOsd` 校准，相同时不重复提示。
断线后清除预计值，下一次滚动从当前实际值开始，系统音量保持独立。
图标优先读取已安装小部件附带的 SPlayer SVG，源码运行使用仓库内 SVG，缺失时使用 SPlayer-Next 主题图标。
`instantFeedback` 默认开启，配置入口在“交互与离线”。Bridge 为各操作保留独立请求编号、预计值和发送状态，
点击时立即发送独立 XMLHttpRequest；开启时显示预计的播放状态、收藏、模式、定位和选曲高亮。
按钮以主题强调色提示待处理操作，失败只删除该请求的反馈，保留较新请求；
播放／模式等绝对状态带输入序号，较旧请求不能覆盖较新的目标。
插件按播放控制、曲目操作、播放模式、音量和队列读取分别串行执行，独立操作之间并行；
“播放我喜欢的音乐”同时占用曲目和模式顺序，定位携带曲目标识并在执行前再次校验。
插件回传逐个命令的 `results`，辅助服务在 `/state.commandResults` 中供 UI 关联成功或失败。
发送超时会取消等待并撤回反馈；已接收的操作等结果或实际状态确认后再结束反馈。
关闭即时反馈时保留即时发送及后台并行，只用播放器实际状态显示按钮和音量 OSD。
Cover 使用两个异步图片槽，在新图片加载完成前保留当前封面，失败时回退占位图。
完整歌词自动跟随对 contentY 执行有限时长动画，手动滚动会中止动画并保留原有 4 秒恢复规则。

SP 主题和语言的持久化数据实际位于
`Partitions/main/Local Storage/leveldb`，并非主进程 settings.json。
辅助程序只读 WAL 和 SST，支持 Snappy 压缩、序列号和删除记录，不锁定或写入 SP 数据库。
主题和 MPRIS 检查在后台进行，避免阻塞歌词通信。
支持明暗／system、自定义主题色和图片主题中的已持久化背景取色。
封面动态取色没有持久化到 theme store，当前回退 Plasma 主题；
无法读取本地主题时也回退 Plasma，见验证记录。

## 默认细节

1.0 默认方形封面，圆形旋转默认关闭；旋转周期 20 秒，与歌词切换过渡独立。
圆形遮罩在 Plasma 6 使用 QtQuick.Effects，Plasma 5 使用 QtGraphicalEffects；
圆角方形复用遮罩，圆角程度为短边的 1–49%，默认 25%；只对圆形启用旋转。
未播放图标保持原形，暂停冻结旋转角度，隐藏或关闭旋转时停止动画。
没有当前歌曲、显示“未在播放”时点击默认打开 SPlayer，改为“播放我喜欢的音乐”后才自动播放。
播放、暂停、加载及停止后仍保留歌曲信息时，继续遵循原有点击主体设置，控制按钮仍保留各自操作。
悬停控制只在已有歌曲的播放或暂停状态显示，空闲、加载、停止、离线及未连接时立即隐藏。
弹窗音量使用绝对值，拖动以 120 ms 合并请求，松手立即提交；键盘每步 1%。
暂停或没有当前曲目时，只要插件连接，仍可调整音量。

双行、优先翻译、单行不优先辅助、基准字号 14／第二行 0.82 倍、
封面左侧、自动宽度、固定宽度 320、自动最大宽度 420（整个部件）、
默认点击完整歌词面板、离线图标、默认启动 SP、歌词点击跳转开启。
鼠标滚轮每步调音量 5%；弹出面板默认 480×560，手动滚动后 4 秒恢复跟随。
前奏／没有歌词时回退歌曲信息，最后一句辅助缺失时第二行空白。
没有时间的歌词可以展示，禁止按该句跳转；逐行歌词不伪造逐字时间。
