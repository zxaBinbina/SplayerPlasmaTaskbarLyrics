# SplayerPlasmaTaskbarLyrics 需求文档

确认日期：2026-11-20

本文记录需求访谈中最终确认的方案，作为设计、开发和验收的依据。
2026-11-20 后续变更：用户要求将设置入口改到 Plasma 小部件，并修复修改字号不生效的问题。
2026-11-20 后续变更：用户要求增加动画效果；具体过渡方式和动画开关按下文实现选择。
2026-11-20 后续变更：歌词弹窗增加播放模式、收藏、播放列表按钮；悬停区增加可关闭的收藏按钮。
未指定的参数数值和实现细节见文末，后续需求变更应更新本文。

2026-11-22／1.0 正式版变更：

- 封面可设置圆形或方形，圆形可进一步开启播放时旋转；暂停时冻结。
- 未播放时点击可设置为打开 SPlayer，或自动播放“我喜欢的音乐”；关闭时先启动。
- 弹窗增加打开 SPlayer 按钮和音量滑块。
- 用户随后取消全部私人 FM 相关功能，自动播放仅保留喜欢的音乐；播放模式按钮沿用原行为。
- 两边插件版本统一为 1.0.1，正式发布，保留原插件 ID。
- 自动播放复用 SPlayer 官方 API 5 和网易云登录状态，需要 `api` 权限；
  不修改 SPlayer 程序或数据库，喜欢歌曲插入原队列之后续播。

## 1. 项目目标与交付组成

| 项目 | 已确认要求 |
| --- | --- |
| 全名 | SplayerPlasmaTaskbarLyrics，与当前项目目录名称一致 |
| 简称 | SPTL |
| SP | SPlayer Next |
| 目标 | 在 KDE Plasma 任务栏固定一个小部件，显示当前播放歌曲的歌词、封面和相关信息，提供播放控制 |
| 功能参考 | SP Windows 版本的任务栏歌词功能；具体行为以本文确认的要求为准 |
| 交付组成 | SP 插件、外部辅助程序、Plasma 小部件，以及相应安装和使用说明 |
| 开源许可证 | AGPL-3.0 |

优先兼容未经修改的官方 SP 安装包。通过现有插件接口与外部辅助程序完成对接，第一版不以修改或重新编译 SP 为安装前提。

## 2. 运行环境与配置范围

- 同时支持 Plasma 5 和 Plasma 6
- 第一版支持顶部、底部的横向任务栏
- 第一版不要求竖向任务栏布局
- 允许在多个屏幕或任务栏添加小部件，全部共享一套配置
- 界面提供中文和英文，默认跟随 SP 的语言设置
- 安装优先采用无需管理员权限的用户级方式

## 3. 任务栏歌词布局

### 3.1 默认双行模式

| 区域 | 内容 |
| --- | --- |
| 第一行 | 当前歌词原文 |
| 第二行 | 当前歌词翻译／音译，或下一句歌词 |
| 字号关系 | 第二行字体小于第一行 |

2026-11-20 后续调整：组件使用横向任务栏的完整可用高度，视觉高度与数字时钟相当。
两行文字和封面垂直居中，避免整体向下偏移和底部截断。
任务栏高度可调整，组件需实时适配：封面、文字、间距和悬停按钮随高度缩放，
字号设置作为 42 像素组件高度下的基准；空间不足时自动缩小文字，保持两行完整显示。

默认优先显示翻译，允许在设置中切换为音译，也允许关闭辅助歌词显示。关闭辅助歌词或所选内容不存在时，第二行沿用 SP Windows 版本的下一句歌词逻辑。

音译支持以 SP 提供的数据为准。调研确认，当前解析歌词接口包含 `romanLyric` 音译字段，可以支持；没有音译内容的歌曲需要正常回退显示。

### 3.2 单行歌词模式

“单行”指一行歌词，整体仍保留两行布局。

| 区域 | 内容 |
| --- | --- |
| 第一行 | 当前歌词，可配置为优先显示翻译／音译 |
| 第二行 | 当前歌曲名称和作者／歌手 |

所选翻译／音译不存在时，第一行回退显示当前歌词原文。此模式应与只显示一行文字的布局区别开来。

### 3.3 封面

- 单行和双行模式都必须显示歌曲封面
- 封面位置可配置为歌词左侧或右侧
- SP 正在运行但没有播放歌曲时，封面区域使用 SP 软件图标
- 歌曲封面缺失或加载失败时，需要保留图片占位；具体占位图片属于实现细节

## 4. 歌词同步与文字滚动

- 支持逐字卡拉 OK 高亮，使用 SP 输出的逐字时间数据
- 没有逐字时间信息时，退化为逐行同步显示
- 暂停时保留歌词和封面，逐字高亮停留在暂停位置
- 歌词、翻译、音译、歌名、作者等长文字超出可用宽度时，必须自动横向滚动
- 自动滚动同样适用于鼠标悬停后显示的歌曲信息
- 逐字歌词的横向滚动应配合当前演唱位置，使正在演唱的内容可见
- 翻译／音译是否具有逐字时间信息，应按实际数据决定；缺少逐字时间时采用逐行显示

## 5. 小部件宽度

- 支持设置固定宽度
- 支持自动宽度：根据当前显示内容动态伸缩
- 支持设置最大宽度，限制自动宽度
- 最大宽度约束整个任务栏小部件，布局应计入封面、文字、播放控制及必要间距
- 达到宽度限制后，超长文字仍通过自动滚动显示

固定宽度、自动宽度的默认选择以及具体宽度数值没有单独指定，开发时选取合理默认值。

## 6. 鼠标交互与播放控制

### 6.1 悬停

鼠标悬停时：

- 第一行歌词替换为歌曲名称
- 第二行歌词／歌曲信息替换为作者／歌手
- 显示上一首、播放／暂停、下一首按钮
- 默认另显示收藏按钮，可在小部件设置中关闭；此开关只影响悬停区
- 封面继续显示

播放控制与封面位于文字两侧，位置关系如下：

| 封面位置 | 悬停后的排列 |
| --- | --- |
| 左侧 | 封面 → 歌曲信息 → 播放控制 |
| 右侧 | 播放控制 → 歌曲信息 → 封面 |

控制按钮不覆盖在封面上。鼠标离开后恢复相应歌词布局。

### 6.2 点击主体

点击歌词或封面的行为可设置为：

1. 展开完整歌词弹出面板，默认行为
2. 不执行任何操作
3. 打开 SP 主窗口

点击播放按钮应执行相应播放操作，避免同时触发小部件主体的点击行为。

### 6.3 滚轮

在任务栏小部件上滚动鼠标滚轮，用于调整 SP 播放音量。

## 7. 完整歌词弹出面板

弹出面板包含：

- 随播放同步的完整歌词
- 歌曲封面
- 歌曲名称和作者／歌手
- 可拖动的播放进度条，用于调整播放位置
- 上一首、播放／暂停、下一首等已确认的播放控制
- 播放模式按钮：列表循环、单曲循环、随机播放，显示当前模式
- 收藏按钮：反映 SP 的收藏状态，点击收藏／取消收藏
- 播放列表按钮：在同一弹窗内查看当前队列、翻页和点击歌曲播放，再次点击返回歌词

默认支持点击某句歌词，跳转到该句播放；允许在设置中关闭此行为。没有可用时间信息的歌词不能进行相应时间跳转。

面板应同步反映切歌、暂停、恢复和拖动播放进度后的状态。面板尺寸、具体字号、歌词滚动布局等细节没有单独指定，开发时选取合理默认值。

## 8. 未运行、空闲与暂停状态

| 状态 | 任务栏表现 |
| --- | --- |
| SP 未运行，默认设置 | 收起为一个图标 |
| SP 未运行，可选设置 | 完全隐藏并释放所占宽度 |
| SP 运行，但没有播放歌曲 | 第一行显示“未在播放”，第二行显示“SPlayer Next”，封面使用 SP 软件图标 |
| 已加载歌曲并暂停播放 | 保留当前歌词和歌曲封面，高亮停在暂停位置 |

SP 未运行、显示收起图标时，点击行为可设置为：

1. 启动 SP，默认行为
2. 不执行任何操作

暂停与“没有播放歌曲”应作为不同状态处理。中文空闲文案按上表显示，英文界面提供相应翻译。
2026-11-22 澄清：“未播放时点击”指没有当前歌曲、小部件显示“未在播放”的空闲界面，
不包含已加载歌曲的暂停状态；暂停时遵循原有“点击主体”设置，默认打开完整歌词弹窗。
后续更改暂不发布到各个商店，本次修正只更新工作区和本机。

2026-11-22 后续补充：空闲、加载、停止和未连接时，悬停不显示操作按钮；已有歌曲暂停时保留控制。
私人 FM 时隐藏播放模式按钮，把弹窗及悬停区的上一首都替换为“不喜欢”；自动开始播放仍仅保留喜欢音乐。
修复 SPlayer 已运行时主窗口唤起无反应的问题。
任务栏悬停区的四个操作按钮不显示浮动文字提示，弹窗内按钮保留原有提示。
滚轮调整 SPlayer 音量时立即使用 KDE 原生 OSD 显示预计的新百分比、SPlayer 名称和 SPlayer 图标。
每滚动一次立即发送一次绝对音量设置，连续滚动累计预计值，不等调整结束才发送；
延迟返回的旧音量不覆盖正在调整的预计值，结束并确认后按实际值校准，随后自动隐藏。
滚轮输入支持鼠标、触摸板及系统合成滚动事件，封面、歌词和操作按钮区域均可调节音量。
设置侧栏语言与设置页面一致；原生关于页的查看许可证按钮显示项目 AGPL 全文。
选择跟随 SP 而无法读取其主题色时，在设置页显示警告并说明回退到 Plasma 配色。
封面新增圆角方形，圆角程度可设短边的 1–49%，排除纯方形和圆形，不可旋转。

## 9. 统一设置与主题

### 9.1 设置入口

用户可编辑的设置统一放在 **Plasma 小部件的原生配置窗口**。右键小部件打开配置，点击“应用”或“确定”保存，取消放弃未应用的编辑。外部辅助程序和所有 Plasma 小部件接收并应用同一套设置。

这是用户后续确认的配置方案，替代最初的 SP 插件设置入口。配置由辅助程序持久化，全体小部件共享；SP 插件不再提供外观设置或回写设置。
字号作为组件高 42 像素时的缩放基准，第二行保持较小字号。
此后续自动适配要求替代先前固定像素字号方案，任务栏高度改变时自动缩放，
较矮面板或过大基准字号下缩小文字以容纳两行。

至少覆盖以下设置：

| 设置项 | 可选内容／要求 | 已确认默认值 |
| --- | --- | --- |
| 歌词模式 | 双行歌词；单行歌词加歌曲信息 | 双行歌词 |
| 辅助歌词 | 是否显示翻译／音译，选择翻译或音译 | 优先翻译 |
| 单行内容 | 是否优先显示翻译／音译 | 具体开关默认值未单独指定 |
| 字体大小 | 可调整字号，第二行保持较小字号 | 具体数值未单独指定 |
| 封面位置 | 歌词左侧或右侧 | 未单独指定 |
| 宽度模式 | 固定宽度或自动宽度 | 未单独指定 |
| 固定宽度 | 可设置 | 数值未单独指定 |
| 最大宽度 | 可设置，限制自动宽度 | 数值未单独指定 |
| 主体点击行为 | 完整歌词面板；无操作；打开 SP 主窗口 | 完整歌词面板 |
| SP 未运行时的显示 | 收起为图标；完全隐藏并释放宽度 | 收起为图标 |
| 收起图标点击行为 | 启动 SP；无操作 | 启动 SP |
| 点击完整歌词跳转 | 开启或关闭 | 开启 |
| 主题模式 | 跟随 SP；跟随 Plasma；手动选择 | 跟随 SP |
| 手动主题 | 可选择明暗和主题色 | 具体颜色未单独指定 |
| 界面动画 | 开启或关闭；速度跟随 KDE 系统动画设置 | 开启 |
| 悬停收藏按钮 | 开启或关闭；弹窗中的收藏按钮保留 | 开启 |

### 9.2 主题来源

- 默认跟随 **SP 主程序**的主题，包括明暗和主题色
- 提供切换到 Plasma 系统主题的选项
- 提供手动选择主题的选项
- “跟随 SP”指其主程序主题，不是 Windows 任务栏歌词专用外观设置
- 现有插件 API 没有直接公开 SP 主程序主题；可由外部辅助程序读取本地主题配置，尽量实现自动跟随
- 本地配置路径、动态主题解析和读取失败时的回退策略，需要在实现阶段核实

## 12. 实现阶段需核实的细节

以下事项没有单独指定，属于后续实现选择或兼容验证事项，不代表用户增加了额外功能要求：

- Plasma 5、6 各自的最低小版本、Qt 依赖、Wayland／X11 适配与测试范围
- 辅助程序的技术实现、启动方式、进程管理、数据同步和通信机制
- SP 插件最低 API 级别、必要权限，以及稳定且全局唯一的插件 ID
- 各种官方 SP 安装方式下的主题配置定位、主题解析和主窗口唤起方式
- 默认字号、宽度、封面位置、间距、滚动速度和音量调节步长
- 完整歌词面板的尺寸、字体和自动／手动滚动的配合方式
- 有歌曲但没有歌词、前奏／间奏、最后一句、图片缺失等边界显示
- SP 运行但插件未启用、辅助程序未安装或断开连接时的提示与恢复
- 安装、更新、卸载流程，以及各发布平台要求的安装包格式和材料

实现时优先使用合理默认值、现有 SP 数据和原生 Plasma 行为。若具体实现需要改变已确认的交互或兼容要求，应先说明影响并更新本文。
