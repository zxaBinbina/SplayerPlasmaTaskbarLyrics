## 已知限制与回退

- SP 的动态封面取色没有持久化到 theme store，插件 API 也没有提供该颜色。
  此来源目前回退 Plasma 主题；明暗、自定义色和持久化图片背景色可以只读跟随。
- streaming-cover 封面通过 SP MPRIS 发布的图片文件读取。
  SP 关闭系统媒体控件、图片不可读或时间上尚未更新时显示占位图。
- 翻译只有逐行文本时不伪造逐字高亮。
  音译的 romanWord 与 romanLyric 精确对应且时间有效时可逐字显示，否则逐行显示。
- 主窗口唤起优先 MPRIS Raise；不可用时走安装入口。
  AppImage 无桌面入口时需要安装参数指定启动命令。
- Plasma 5 包已生成并检查内容；当前环境缺少 Plasma 5 的 Plasma/Applet
  package structure 和对应 QML 模块，不能据此宣布 Plasma 5 实机兼容已通过。

## 安装崩溃回归

默认安装最初直接运行 plasmashell --version，缺少显示会话变量时 Qt 初始化中止（SIGABRT）。
现改为优先 KDE_SESSION_VERSION、否则 Qt 离屏检测，并对异常退出／超时提供明确错误。
桌面外命令环境缺少用户 D-Bus 变量时，只尝试当前用户拥有的运行目录与总线；
无法连接用户级 systemd 时在修改安装文件前停止。

6 项回归覆盖无显示环境、当前会话优先、SIGABRT、超时、显式总线保留和会话缺失。
隔离安装测试已改为使用默认自动检测入口；实际 python3 tools/install.py 返回 0。

## 真实桌面的旧组件缓存

用户反馈字号仍小后，核实共享配置和已安装代码均为 32 像素，
但真实任务栏小部件只有 26 像素高，仍呈现旧版按高度缩小字号的表现。
Panel Colorizer 的字体覆盖未启用，排除其配置覆盖字号。

执行 `python3 tools/install.py --reload-plasma` 更新并重启 Plasma 外壳后，
实际任务栏截图确认字号明显增大，用户也确认“变大了”。
因此“移除后重新添加”不足以保证丢弃进程内 QML 缓存；更新说明已修正。
默认安装不重启 Plasma，显式重载仅在用户级 Plasma 服务正在运行时执行。
隔离安装／更新／卸载验证包含该选项，并模拟服务重载。

当前任务栏高度为 46 像素，主题边距后给小部件分配 26 像素。
实机截图中的 32 像素字号已生效，但较矮面板不足以完整容纳两行，大字号需要提高面板高度。
此高度限制与字号是否生效分别记录，不再据离屏字号断言推断真实任务栏显示完整。

还补齐了真实 Plasma 配置加载时传入的默认元数据和面板布局属性，
避免原生配置窗口报告缺少 cfg_settingsRequestDefault、cfg_length 和 cfg_expanding。
